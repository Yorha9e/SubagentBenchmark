03 / PLAN EFFECT

phi_3 计划增益（B − A）

正向柱 = 读计划后 raw criterion 提升；反向柱 = 退步。17 候选中 9 提升、6 不变、1 下降（composer-2.5 † 另计 +2），中位增益 +1——计划是弱模型助推器，对强模型多为零增益甚至反向。

B12（mimo-v2.5-pro）的 strict task Δ=-2 来自 Gate 清零，代码完成度应看 Raw Δ=+1 且 token -55%；minimax-m3 是唯一被计划带偏（-2）的模型。composer-2.5 † 为 Cursor harness，token N/A。grok-4.5 ‡（A16→B16）raw/strict 均 +0；hy3 §（A17→B17）raw +2 但 .pytest_cache 触发 Gate，strict task Δ=-2——两者 token 均 N/A。
04 / MODEL EVALUATION

模型逐个评价 · 多轴证据卡

每张卡保留原有多轴证据，并单独补充 Reviewer 的 B11 快速发现 / 快速修复评价；该评价不与短任务、长任务或 Critic 组合推导，也不生成综合总分。

整体判断：qwen 是长任务持续执行冠军，luna 是 Reviewer 调试冠军，kimi 是 Critic 盲审冠军兼跨条件最稳定的通用候选；glm-5.2 是任务限定的短任务实现强者，mimo-v2.5-pro 是高效率但存在类型、审计与 replay 泛化缺口的候选。2/10 长任务组内部能力差异明显；Gate FAIL 应与 raw completion 并列解释，而不是被简化成“没有实现”。新增 5 个长任务补充候选（claude-fable-5 双档、claude-sonnet-5、grok-4.5、hy3）全部因同一 workspace audit 规则 Gate FAIL——其中 fable-5 raw 8/10 追平 qwen，是严格榜之外最值得关注的原始完成度证据。Critic 轴上 kimi 与 doubao-seed-evolving ✦ 并列 GT 全中（92.3 分），evolving 同时是短任务 A 满分 + Reviewer 8/8（性能全榜最快），是排除 gpt 后唯一三轴满分的全能候选；doubao-2.0-pro 以 68s/90 分成为快速反馈场景的实用默认但漏 GT2。
