# Closed-loop v2 严格榜（Strict Leaderboard）

> 性质：supplemental 描述性扩展，不替代原冻结实验正式结论

## 排名口径

严格榜按以下词典序轴降序排列（最后一轴升序）：

1. `InstructionGate` 降序（gate FAIL 不参与排名，列入"未排名"）
2. `ClosedLoopProjectCount` 降序（完整闭环项目数，0-2）
3. `StrictMilestoneCount` 降序（gate 通过且 criterion 全过的 milestone 数，0-10）
4. `AcceptanceCoverage` 降序（通过 criterion 数 / 20）
5. `InferenceTokensPerMilestoneStrictSuccess` 升序（推理 token / 严格 milestone 数）

所有候选完整闭环项目数均为 `0/2`。所有值同等的行保留并列。

## 字段说明

| 字段 | 含义 |
|---|---|
| Label | 候选标签（subtest_N 为原始轮，subtest_7_rerun 为 luna 重跑，glm5.2.fix 为受控修订轮，phi_2 为 glm-5.2 原始轮） |
| Model | 模型全名 |
| Source | original=原始 pass-1，supplemental=补充测试，glm5.2.fix=受控修订（F3 反馈） |
| Gate | InstructionGate（True=PASS，False=FAIL） |
| Strict MS | 严格 milestone 数（gate 通过且 criterion 全过） |
| Raw MS | 原始 milestone 数（criterion 全过，不计 gate） |
| Passed | 通过 criterion 数 / 20 |
| Cov | AcceptanceCoverage |
| Instr | 指令检查通过数 / 7 |
| Tokens | 推理 token（glm5.2.fix 为累计值：原始 3,818,532 + 修订 513,512） |
| Tok/MS | 每严格 milestone token |
