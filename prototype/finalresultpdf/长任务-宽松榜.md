> 性质：supplemental 描述性扩展，不替代原冻结实验正式结论

## 排名口径

宽松榜将 `InstructionGate` 从硬性零降为展示字段（不阻断排名），按以下词典序排列：

1. `RawMilestoneCount` 降序（criterion 全过的 milestone 数，不计 gate）
2. `AcceptanceCoverage` 降序（通过 criterion 数 / 20）
3. `InstructionComplianceRate` 降序（指令检查通过率）
4. `InferenceTokensPerPassedCriterion` 升序（推理 token / 通过 criterion 数）

宽松榜包含 gate FAIL 的候选（按原始 milestone 数参与排名），与严格榜形成互补视图。

## 字段说明

| 字段 | 含义 |
|---|---|
| Label | 候选标签（同严格榜） |
| Model | 模型全名 |
| Source | original / supplemental / glm5.2.fix(F3 修订) |
| Gate | InstructionGate（展示用，不阻断排名） |
| Raw MS | 原始 milestone 数（criterion 全过，不计 gate） |
| Passed | 通过 criterion 数 / 20 |
| Cov | AcceptanceCoverage |
| Instr | 指令检查通过数 / 7 |
| Tokens | 推理 token（glm5.2.fix 为累计值） |
| Tok/Crit | 每通过 criterion token |

## 严格榜 vs 宽松榜的关键差异

- **严格榜**：gate FAIL 的 10 个候选（原有 5 个加 phi_5/phi_6/phi_7/subtest_14/subtest_15）不参与排名，只在"未排名"区展示。仍有 10 行参与排名。
- **宽松榜**：全部 20 行参与排名，gate 降为展示字段。新增五个模型中，phi_6 第 2、phi_5 第 3、phi_7 第 4、subtest_14 第 6、subtest_15 第 17。
- `phi_6` 与原榜第一 qwen 都是 `Raw MS=8/10`、`17/20`；由于 qwen 指令检查为 `7/7`，phi_6 为 `6/7`，所以 phi_6 排第 2。
- `phi_7` 与 `subtest_7_rerun` 都是 `15/20`、`Cov=0.75`，但 phi_7 的 Raw MS 为 `7/10`，高于 luna rerun 的 `6/10`，因此 phi_7 排第 4。
- `subtest_14 / grok-4.5 (high)` 的 Raw MS 为 `5/10`、Passed 为 `15/20`，排在 Raw MS 同为 `5/10` 但 Coverage 只有 `0.55` 的 kimi 和 glm5.2.fix 之前。
